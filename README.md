# Дневник практики 📝

Мобильное веб-приложение для учета практических заданий с генерацией отчетов через Gemini AI.

## Функционал

- ✅ Авторизация пользователей (Firebase Auth)
- ✅ Дневник с автоматическим подсчетом часов
- ✅ Контакты руководителей
- ✅ Генерация отчетов через Gemini AI
- ✅ Загрузка примера отчета (поддержка .docx и .txt)
- ✅ Экспорт отчета в PDF и Word (.doc)

## Установка для друга

1. Создайте файл `firebase-config.js` на основе настроек вашего Firebase проекта
2. Получите API ключ Gemini на [Google AI Studio](https://aistudio.google.com/apikey)
3. Загрузите файлы на хостинг или откройте локально

## Технологии

- Firebase (Auth, Firestore)
- Google Gemini AI
- HTML2PDF
- Mammoth.js (для чтения DOCX)

## Безопасность

- API ключ Gemini хранится только в localStorage браузера
- `firebase-config.js` исключен из Git через .gitignore
- Каждый пользователь использует свой ключ Gemini
