# Дневник практики 📝

Мобильное веб-приложение для учета практических заданий c ии агентом.

## Функционал

-  Авторизация пользователей (Firebase Auth)
-  Дневник с автоматическим подсчетом часов
-  Контакты руководителей
-  Генерация отчетов через Deepseek
-  Загрузка примера отчета (поддержка .docx и .txt)
-  Экспорт отчета в PDF и Word (.doc)

## Установка для друга

1. Создайте файл `firebase-config.js` на основе настроек вашего Firebase проекта
2. Получите API ключ Deepseek
3. Загрузите файлы на хостинг или откройте локально

## Технологии

- Firebase (Auth, Firestore)
- Deepseek
- HTML2PDF
- Mammoth.js (для чтения DOCX)
